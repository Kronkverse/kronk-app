Kronk for Android
=================

The Android app for [Kronk](https://kronk.info). It opens Kronk full-screen as a
Trusted Web Activity, so everything new on the site is in the app the moment
it deploys.

## Download

[kronk.info/kronk.apk](https://kronk.info/kronk.apk). Test builds are listed at
[kronk.info/dev](https://kronk.info/dev/).

## Building

JDK 17 and the Android SDK (platform 36, build-tools 35).

```bash
./gradlew assembleLiveRelease     # info.kronk.app → kronk.info
./gradlew assembleShadowRelease   # info.kronk.app.shadow → shadow.kronk.info
```
